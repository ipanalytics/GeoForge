# release/

Сюда попадают результаты сборки.

- `geo.mmdb` — итоговый собранный файл MMDB, конечный артефакт поставки.
- `geo.csv` — плоская аудиторская копия тех же записей, используется проверкой качества.
- `geo.previous.csv` — предыдущая аудиторская копия, сохраняемая перед новой сборкой.
- `geo-quality-report.txt` — отчёт о качестве после сборки, сравнивающий новый релиз
  с предыдущей аудиторской копией.

Синхронизируйте эту папку с тем путём, который ожидает ваш PHP-код / приложение:
в примере `index.php` чтение выполняется из `db/geo.mmdb`, поэтому при развёртывании
обычно копируют `release/geo.mmdb` в `<docroot>/db/geo.mmdb`.
